# ZFL Launcher on a real phone

Captured on a POCO X5 running Android 14, at 1080×2400 with density 375,
on October 15, 2026. The system language was English (United States), and
the weather city was Warsaw. Installed apps were temporarily arranged for
the showcase; screenshots contain no Russian apps.

The PNGs are direct, full-resolution device captures. The wallpaper, icons,
glass surfaces, widgets, menus, and animations were rendered by the installed app.
The original launcher layout, preferences, weather city, system language,
app availability, and display settings were restored after capture.

## Page transitions

Each recording shows the same four 350 ms swipes between the same two home
pages. The selected transition was changed through the launcher's settings
before each recording. No motion interpolation was used.

| Effect | GIF preview | 60 fps video |
|---|---|---|
| Default | [GIF](transitions/default.gif) | [MP4](transitions/default.mp4) |
| Rotation | [GIF](transitions/rotation.gif) | [MP4](transitions/rotation.mp4) |
| Flip | [GIF](transitions/flip.gif) | [MP4](transitions/flip.mp4) |
| Zoom In | [GIF](transitions/zoom-in.gif) | [MP4](transitions/zoom-in.mp4) |
| Alpha | [GIF](transitions/alpha.gif) | [MP4](transitions/alpha.mp4) |

Every export contains 360 frames over six seconds. MP4 files are 720×1600
at a constant 60 fps. GIFs are 360×800 and use alternating 10/20 ms frame
delays to average 60 fps; GIF timing has 10 ms precision, and some viewers
slow down short frame delays. Use the MP4 versions for consistent playback.

Android's original recordings have variable frame intervals, including longer
holds when the screen is still. The median interval among source frames less
than 25 ms apart was 16.57–16.71 ms across the five recordings. Constant-rate
exports repeat held frames where needed. These captures show the effects;
they are not a performance benchmark.
